# YEG Custom Windows

Website for [yegcustomwindows.ca](https://www.yegcustomwindows.ca), an Edmonton window, door and glass company.

The site is built, hosted and published in **Webflow** (site: "Yeg Custom Windows"). This repository does not hold the site's code; it tracks changes made to the Webflow site, such as SEO fixes from SE Ranking audits.
